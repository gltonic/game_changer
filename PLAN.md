# Нейробиологический трекер привычек (Telegram Mini App)

## Концепция
Telegram-приложение для формирования привычек с использованием геймификации, визуального прогресса и дофаминового подкрепления.

## Архитектура
*   **Frontend:** Telegram Web App (React / Vue, Vite, TailwindCSS)
*   **Backend/Database:** Supabase или Firebase (или Node.js + PostgreSQL)
*   **Bot:** Telegram Bot API (Node.js / Telegraf) для отправки push-уведомлений и триггеров.

## Основные фичи (MVP)
1.  **Дашборд:** До 5 активных привычек. Отображение стриков и жизней (сердечек).
2.  **Визуальная тропа (Path):** Экран в стиле Duolingo с прогрессом (кружочки).
3.  **Карточка дня:** Инструкция на день (микро-урок).
4.  **Геймификация:**
    *   Жизни (3 на старте)
    *   Стрики (дни подряд)
    *   Заморозка (1 раз в месяц)
    *   Эмоциональный фидбек (конфетти, вибрация)
5.  **Система уведомлений (Триггеры):** Push-уведомления от бота со ссылками на Mini App.
6.  **Магазин Гайдлайнов (Marketplace) - v2:** Предустановленные пути (шпагат за 90 дней и т.д.).

## План разработки
1.  **Инициализация проекта:** Настройка монорепозитория (Frontend + Backend/Bot).
2.  **Разработка UI/UX:** Создание дашборда, визуальной тропы и карточки дня (моки данных).
3.  **Интеграция с Telegram:** Подключение Telegram Web App SDK, получение данных пользователя.
4.  **Бэкенд и База данных:** Настройка схемы БД (пользователи, привычки, прогресс).
5.  **Бот и Уведомления:** Настройка отправки напоминаний.
6.  **Тестирование и деплой.**
